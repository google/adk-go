# Changelog

## [2.8.0](https://github.com/google/adk-go/compare/v2.7.1...v2.8.0) (2026-11-13)


### ⚠ BREAKING CHANGES

* **configurable:** an absolute config_path is no longer accepted in workflow edge references, matching what #878 did for agent references. A reference reached through a link anywhere inside the config directory no longer loads either, for agent and workflow references alike, wherever that link points — this refuses config directories materialised entirely from symlinks (Kubernetes ConfigMaps and projected volumes, Bazel runfiles, Nix store paths); stage such a mount into a directory of real files (e.g. cp -rL) before pointing the agent at it.
